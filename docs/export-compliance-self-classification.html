3. Product Description

Barys VPN is a free consumer mobile VPN (virtual private network) client for iOS and Android. It establishes an encrypted tunnel between the user's device and a remote proxy server to protect the confidentiality of the user's internet traffic. The application is a mass-market product distributed to the general public through the Apple App Store and Google Play with no restriction on the class of end user.

4. Cryptographic Functionality

The application uses only standard, publicly available encryption algorithms accepted by international standards bodies (IETF/ISO/NIST). No proprietary or non-standard cryptography is implemented.
